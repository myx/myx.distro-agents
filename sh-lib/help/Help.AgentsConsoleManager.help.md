📘 syntax: AgentsConsoleManager.fn.sh [--help-syntax]
📘 syntax: AgentsConsoleManager.fn.sh [--help]

##  Summary:

		Opens the agents console's manager screen in this terminal, on
		the start options below. With no arguments it opens the screen
		at its list, where the keys are.

##  Options:

		--style <name>
			The interface style of this start, as --manager takes it.

		--component <path>
			Opens the list at that component level: its ids, / between
			them.

		--view list|view
			Which window has the keys. The start gives them to the list.

		--filter <text>
			Narrows the table of the left window, and gives it the keys.

		--dialog <name>
			Shows that one dialog and ends when it is closed
			(single-dialog mode).

		--text <text>
			The words of that one dialog.
