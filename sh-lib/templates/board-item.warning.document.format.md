# board-item.warning document — the shape of one warning

Normative contract: `board-item.warning.contract.format.md` (the skillset). Where it and this skeleton disagree, the contract wins. This file carries the skeleton the board writer fills from the member's slots, and states the slots.

# Summary

An open risk, kept visible in an active state until it is mitigated, accepted or converted. Every spawn brief lists the open ones.

# Skeleton

## document
```
# Warning: {{matter}}

{{body}}
```

# Slots

- `matter` — the matter, one line, the title after `# Warning:`.
- `body` — the risk, what it endangers, and what would mitigate it.
