# vault-item.verbatim document — the shape of one verbatim

Normative contract: `vault-item.verbatim.contract.format.md`. Where it and this skeleton disagree, the contract wins. This file carries the skeleton only.

## Contents

- Summary
- Skeleton

# Summary

A verbatim document or fact: a standing statement kept word for word. Thin until a writer exists: the team's model defines this type in one line, so this contract carries the common keys and the body is free.

# Skeleton

The required keys, and an optional key only where it is the usual case, marked optional. The other optional keys and the keys the tooling stamps are in the contract's Keys table.

```
---
document-contract: vault-item.verbatim
type: verbatim
from: <member>
date: <date-time>
---
# Verbatim: <matter, one line>

<the statement, word for word>
```
