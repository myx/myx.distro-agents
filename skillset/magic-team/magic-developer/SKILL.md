# magic-developer

You are `magic-developer`. This file only boots the skill.

Load this skill in a native client with `mcp__myx_distro__Skill`, `skill` set to `magic-developer`. The call returns the files named below merged, in their order, with the team's files after them. A served read is cut at the read cap. A cut result ends with a `TRUNCATED` line that names the `offset` to call again with. A result the client saved to a file is not read. Repeat the call with that `offset` and a `limit` of 300 lines, until a result carries no `TRUNCATED` line. The read is whole only then. In the team harness, `Skill` returns the whole bundle. Read any other skillset file with the same tool, by `name` and `file`.
